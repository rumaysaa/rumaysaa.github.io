Full-stack E‑commerce Platform

Organisation
Intelli Vyapar
Role
Web Developer Intern
Dates
Sep – Dec 2023
Location
Surat, India

Overview

An online store built from scratch: customers browse, fill a cart and check out, while the team runs products, stock and orders from an admin panel.

The problem

The business needed its own store instead of relying on marketplaces: secure customer accounts, a catalogue it could manage itself, and a cart and checkout that stayed reliable as the product range grew.

Architecture

Request path every page and action

  1. 01React UICatalogue, cart, checkout, admin
  2. 02Express APIREST routes per resource
  3. 03MiddlewareAuth tokens, roles, validation
  4. 04MS SQL ServerUsers, products, carts, orders

Features

For customers

  • Sign-up and login with hashed passwords and token-based sessions
  • Catalogue with categories, search, filters, sorting and pagination
  • Product pages with images, price and live stock
  • Cart saved to the account, with quantity updates and running totals
  • Checkout and order history with order status

For admins

  • Create, edit and remove products and categories
  • Stock management, with out-of-stock items flagged
  • Order dashboard to move orders from placed to shipped to delivered
  • Admin-only routes protected by role checks on the API

Under the hood

  • REST API organised into Express routers and reusable middleware
  • Relational schema with foreign keys between users, products, carts and orders
  • Parameterised SQL queries to prevent injection
  • Central input validation and consistent error responses
  • Responsive React UI that works on mobile

Challenges

  • ProblemShoppers added items before logging in, then lost their cart when they signed in.

    FixKept a guest cart in the browser and merged it into the account cart on login.

  • ProblemTwo customers could buy the last unit of the same product at once.

    FixChecked and decremented stock inside a single database transaction at checkout.

  • ProblemLoading the whole catalogue at once made listing pages slow.

    FixMoved filtering and pagination to the server, with indexed SQL queries.

My role

Web Developer Intern. I built the Node.js and Express backend end to end: the database schema, REST API, authentication, and the cart and order logic. I also built the React pages for the catalogue and cart.

Tech stack

  • Node.js

  • MS SQL Server

Outcome

A complete store from catalogue to checkout, on a backend that handled every server request and API call reliably.
