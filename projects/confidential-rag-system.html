Confidential RAG System

Overview

A private RAG system that turned 25+ messy legal and policy documents into a searchable knowledge base, so staff could ask questions in plain English and get answers grounded only in company data.

The problem

ChatGPT only knows public data up to its training cut-off. Ask it about a company’s own policies or records and it has nothing to go on. The goal was a question-answer engine that searches a private document index first, then lets the model reason over what it finds.

How it works

Indexing once per document

  1. 01LoadPDF, DOCX, XLSX, CSV, TXT
  2. 02ChunkSplit into passages
  3. 03EmbedPassages to vectors
  4. 04Vector indexPersisted, appendable

Answering per question

  1. 05QuestionEmbedded the same way
  2. 06Semantic searchTop-ranked chunks
  3. 07LLMReasons over those chunks only
  4. 08AnswerGrounded in company data

What I built

  • A RAG pipeline that indexed 25+ unstructured legal and policy documents, with a LlamaIndex loader for each format (PDF, DOCX, XLSX, CSV, TXT) merged into one vector index.
  • An evaluation of OpenAI against self-hosted models (Ollama), so company data stayed secure and compliant on Azure.
  • A persistent index saved to disk, with new uploads appended to the existing index instead of rebuilding it.
  • Token and chunk-size limits on prompts to keep OpenAI API usage and cost under control.
  • A Flask backend with an HTML/CSS/JS chat interface: chat history, typing indicator, theme toggle and a file manager page.
  • Privacy features: password-protected access, and uploads indexed without being saved to disk.
  • Cloud deployment, plus research into Azure OpenAI services and costing.

My role

AI Research & Solutions Intern, 168 hours over four weeks. I built the document loaders, vector index and chatbot logic, and worked with the team on the web interface, password protection and cloud deployment.
