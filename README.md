# Rumaysa Babulkhair: Portfolio

**Live site: [rumaysaa.github.io](https://rumaysaa.github.io)**

Personal portfolio of Rumaysa Babulkhair, Software & AI Engineer based in Dublin, Ireland
(M.Sc. Computer Science, Technological University Dublin).

## What's inside

- **Home page:** intro, an animated diagram of the RAG pipeline behind my AI projects,
  work and internships, about, education, toolbox, references and contact.
- **Project pages** with overview, architecture, features, challenges and tech stack:
  - [AI Study Buddy](https://rumaysaa.github.io/projects/ai-study-buddy.html): M.Sc. final-year project, a local-LLM + RAG study platform with demo video
  - [Employee Management Platform](https://rumaysaa.github.io/projects/employee-management-platform.html): Algobrain AI, face-recognition attendance, RBAC, admin and employee apps
  - [Confidential RAG System](https://rumaysaa.github.io/projects/confidential-rag-system.html): Hexacorp, private document question answering
  - [Full-stack E-commerce Platform](https://rumaysaa.github.io/projects/ecommerce-platform.html): Intelli Vyapar, React + Node.js/Express + MS SQL Server

## Built with

Plain HTML, CSS and JavaScript: no framework, no build step, no dependencies.

- Light and dark themes, saved per visitor
- Responsive from phone to wide desktop
- Scroll-reveal animations, respecting the reduced-motion setting
- Screenshot slider and pipeline animation written in vanilla JS
- Hosted on GitHub Pages

## Run locally

```bash
git clone https://github.com/rumaysaa/rumaysaa.github.io.git
cd rumaysaa.github.io
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Structure

```
index.html          Home page
projects/           One page per project
style.css           All styles
script.js           Theme toggle, menu, animations, slider, video player
assets/             Portrait, demo video and project screenshots
```
